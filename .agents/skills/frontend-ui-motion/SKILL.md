# Frontend UI & Motion Guide

## Design System & Styling
- **Typography & Color**: Use consistent typography and Tailwind design tokens.
- **Animations**: Implement fluid hover, focus, and state transitions using CSS or motion libraries.
- **Responsiveness**: Ensure mobile-first layouts with smooth desktop scaling and clean viewport adaptation.
- **Accessibility**: Use accessible semantic markup, appropriate ARIA roles, and high contrast focus states.
